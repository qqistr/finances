# EcomVision Финансы — Веб-приложение личных финансов

Точная копия и полнофункциональный веб-клон сервиса [app.ecomvision.team/finances/web/](https://app.ecomvision.team/finances/web/), воссозданный с пиксельной точностью по интерфейсу мобильного веб-приложения.

---

## 📱 Ключевые возможности

1. **Дизайн и темная тема iOS (1-в-1 по скриншотам)**
   - Черный фон (`#000000`), карточки с мягким скруглением (`20px - 26px`), разделителями и акцентным синим цветом iOS (`#007aff`).
   - Имитация строки состояния iOS (время, Dynamic Island, LTE, батарея).
   - Плавающий нижний док навигации с размытием фона (Backdrop blur) и быстрой кнопкой поиска `🔍`.

2. **4 основных экрана приложения**:
   - 🏠 **Сегодня**:
     - Начальное состояние с карточками «Начните со счёта» и шагами 1-2-3.
     - Интерактивный виджет **«Ежемесячные платежи»** (расходы на связь, домашний интернет, подписки, ЖКХ, аренда).
     - При наличии счетов: автоматический расчет «Сколько можно тратить в день до зарплаты» с учетом оставшихся дней и обязательных трат.
     - Быстрый ввод трат одной строкой.
     - Список счетов с актуальными балансами.

3. **📱 Меню «Ежемесячные платежи» (Связь, Интернет, ЖКХ, Подписки)**:
   - Добавление и учет всех повторяющихся ежемесячных расходов.
   - Готовые быстрые шаблоны в 1 клик:
     - 📱 Связь (МТС, Билайн, Мегафон, Т-Мобайл)
     - 🌐 Домашний интернет
     - 🎬 Яндекс Плюс и другие подписки
     - 💡 ЖКХ и коммунальные услуги
     - 🏠 Аренда жилья
     - 🏋️ Спортзал
   - Выбор дня списания (например, каждое 15-е число).
   - Кнопка отметки «✓ Оплачено» для контроля текущего месяца.
   - Подсчет общей фиксированной нагрузки в месяц.
   - Доступно из виджета на главном экране, из раздела «План» и через командное меню `🔍`.
   - 📋 **Операции**:
     - Пустое состояние с иконкой кошелька и кнопкой «Добавить счёт».
     - Полный список транзакций с разбивкой по датам, иконками категорий, счетами и подсветкой доходов (+зеленый) и расходов.
   - ⏱ **План**:
     - Метрики в 3 карточки: «Учтено до [даты]», «Защищённый резерв», «Платежей впереди».
     - Блок «Обязательные платежи» (подписки, аренда, кредиты) с кнопкой «Резерв».
     - Блок «Ожидаемые доходы» (зарплата, аванс).
   - 🏁 **Цели**:
     - Фильтры «Все цели», «В процессе», «Достигнуты».
     - Прогресс-бары накоплений, процент выполнения, целевые даты и быстрое пополнение цели.

3. **Умный ввод одной строкой (Natural Language Parser)**:
   - Введите например `Кофе 350` или `Такси 450` или `Зарплата 150000` — приложение само определит категорию, иконку, тип операции (доход/расход) и запишет транзакцию.

4. **Быстрый командный поиск (Command Sheet / Меню действий)**:
   - Открывается по клику на круглую кнопку лупы `🔍` в правом нижнем углу.
   - Полнотекстовый поиск по всем операциям и разделам.
   - Быстрые действия: «Записать операцию», «Новый счёт», «Добавить платёж», «Аналитика», «Помощник», «Настройки».

5. **Режим конфиденциальности (Privacy Mode)**:
   - Кнопка с глазом в верхнем правом углу: скрывает все денежные суммы под маску `•••• ₽` одним кликом.

6. **AI Финансовый помощник**:
   - Интерактивный советник по бюджету, расчету дневных лимитов и оптимизации трат.

7. **Аналитика трат**:
   - Наглядная круговая структура и столбцы категорий расходов в процентах и рублях.

8. **Локальное хранение (Local-first) и резервное копирование**:
   - «Бюджет хранится в этом браузере» — данные сохраняются в LocalStorage.
   - Кнопки экспорта и импорта резервной копии JSON.
   - Кнопка «Загрузить демо-данные» для мгновенного наполнения приложения реалистичными счетами и операциями.

## 🚀 Запуск приложения

### Вариант 1: Через локальный Python-сервер
В терминале перейдите в папку проекта и выполните:
```bash
python3 server.py
```
После запуска откройте в браузере:
👉 **[http://localhost:8080](http://localhost:8080)**

### Вариант 2: Прямое открытие файла
Просто откройте `index.html` двойным кликом в Safari, Chrome или любом мобильном браузере:
```bash
open index.html
```

---

## 📂 Структура проекта
- `index.html` — HTML5 каркас PWA с мета-тегами для мобильных экранов.
- `styles.css` — стили, iOS-дизайн токены, анимации и адаптивность.
- `app.js` — вся логика состояния, парсер текста, расчет лимитов, модальные окна и экраны.
- `server.py` — локальный сервер разработки.
