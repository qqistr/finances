# Finances — Личные финансы и умный бюджет

Современное веб-приложение для удобного ведения личного бюджета, учета расходов, контроля регулярных платежей и накопления на финансовые цели с поддержкой облачной синхронизации между Mac и iPhone.

---

## 🌐 Онлайн-версия

Приложение опубликовано и доступно по ссылке:  
👉 **[https://qqistr.github.io/finances/](https://qqistr.github.io/finances/)**

---

## 📱 Возможности

* **Умный ввод одной строкой**: введите например `Кофе 350`, `Такси 450` или `Зарплата 150000` — категория, иконка и тип операции определятся автоматически.
* **Ежемесячные платежи**: отдельный раздел для постоянных регулярных трат (мобильная связь, домашний интернет, подписки, ЖКХ, аренда, спортзал) с выбором дня списания и отметкой оплаты.
* **Расчет свободного бюджета**: автоматический подсчет безопасного лимита трат в день до следующей зарплаты.
* **Облачная синхронизация между устройствами**: персональный секретный бэкап через GitHub Gist — все данные мгновенно синхронизируются между iPhone, Mac и другими устройствами.
* **Финансовые цели**: наглядные копилки с прогресс-баром в процентах и целевыми датами.
* **План расходов и доходов**: учет обязательных списаний и ожидаемых поступлений.
* **Режим конфиденциальности**: кнопка скрытия сумм под маску `•••• ₽` одним нажатием.
* **AI-Помощник и Аналитика**: рекомендации по оптимизации трат и графики расходов по категориям.
* **100% приватность и локальное хранение**: данные хранятся на ваших устройствах и в вашем личном GitHub.

## 📲 Установка на iPhone как приложение

1. Откройте **[https://qqistr.github.io/finances/](https://qqistr.github.io/finances/)** в Safari на iPhone.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Выберите **«На экран "Домой"»**.
4. Приложение появится на рабочем столе с собственной иконкой и будет открываться в полноэкранном режиме без рамок браузера.
